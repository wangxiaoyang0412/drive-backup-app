Privacy Policy

Last updated: 31 October 2026

Personal Drive Backup is used only by its owner. This policy describes how it handles Google user data.

Data accessed

The tool uses the Google Drive API with the drive.file scope. It can access only the files and folders it has created in the owner's Google Drive. It does not access any other Drive content, contacts or email.

How data is used

The tool uploads backup files that are encrypted before they leave the owner's server, then downloads them again to check that each copy is intact. It does nothing else with Google user data.

Sharing and storage

No data is sold, shared with third parties, or used for advertising or analytics. Backup files stay in the owner's Google Drive. The authorization token is stored only on the owner's own server.

Revoking access

Access can be revoked at any time from the Google Account permissions page.

Contact

Questions can be raised through the GitHub repository that hosts this page.
